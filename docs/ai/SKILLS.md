# Plantilla oficial

## [Nombre del concepto]

### 1. 🧠 Concepto — Qué es

Explicación simple, sin jerga innecesaria.

#### 🧒 Nivel niño de 5 años

Explicación con analogía sencilla.

#### 💻 Nivel ingeniero senior

Explicación técnica para README, hoja de vida, portafolio o GitHub.

#### 🏛️ Nivel arquitecto de software

Justificación estratégica: por qué se usa, qué problema evita, qué trade-offs tiene y cómo se defiende en entrevista.

---

### 2. 💻 Implementación — Cómo se hace

Comando, código, Dockerfile, docker-compose, fragmento C#, YAML o configuración real.

Debe ser código real, no teoría.

---

### 3. 🔍 Análisis del código — La lógica

Responder:

- ¿Por qué funciona así?
- ¿Qué problema resuelve?
- ¿Qué pasaría si cambio X?
- ¿Qué errores comunes pueden ocurrir?
- ¿Qué debo revisar si falla?

---

### 4. ✨ Clean Code & Buenas Prácticas

Responder:

- ¿Qué buena práctica aplica?
- ¿Qué riesgo evita?
- ¿Qué podría mejorar?
- ¿Qué no se debe hacer en producción?

---

### 5. 🚀 Aplicación Real / Contexto Empresa

Responder:

- ¿Dónde lo usaría en mi stack?
- ¿Aplica a .NET API?
- ¿Aplica a Angular?
- ¿Aplica a SQL Server?
- ¿Aplica a CI/CD?
- ¿Cuándo NO lo usaría?

---

### 5.5 🎯 Oferta donde esto importa

Indicar tipos de roles donde este conocimiento suma:

- Backend Developer .NET
- Full Stack .NET Angular
- Senior Software Engineer
- DevOps-aware Developer
- Cloud Developer

Si no aporta a empleo actual, marcar como Parking Lot.

---

### 6. 🎯 Relevancia para mi ENGRAM

Marcar una sola opción:

- 🧩 Principal (.NET + SQL)
- 🔄 Secundario (Python ETL / automatización)
- 📱 Terciario (React Native)
- 🧠 Capa transversal (IA / productividad / infraestructura)
- 🚫 Parking Lot

---

### 7. 🧪 Evidencia que voy a construir

Elegir al menos una:

- ✅ mejora a proyecto existente
- ✅ script funcional
- ✅ Dockerfile
- ✅ docker-compose
- ✅ README con ejemplo
- ✅ endpoint funcionando
- ✅ demo en GitHub
- ✅ captura de terminal
- ✅ prueba técnica

Si no hay evidencia, no guardar como conocimiento principal.

### 8. 📌 Nivel real de dominio
